Layer 2 — Answer-correctness prediction (deliverables #2 + #3)
==============================================================
Generated by src/classify.py  (paper eqs. 7-9)

Method
------
- Target  : label (1=correct, 0=incorrect) from label_answer_data/0{q}total.xlsx
- Features: 3 cognitive-state ratios per (subject, question)
- Model   : NINE item-specific logistic regressions, one per question (eq.8),
            standardised features -- NOT a single pooled model, because the nine
            items differ in difficulty / cognitive demand (paper Table 2).
- CV      : per-question StratifiedKFold (k<=5, clamped to the minority-class
            size). Within a question each subject has exactly one row, so any
            fold split is already subject-independent (no subject spans
            train/test). A question whose minority class has <2 subjects is
            rejected, not silently skipped.
- Score   : sum the 9 per-question predictions per subject -> predicted total
            score, correlated with the true total score (eq.9).
- Rows    : 22 complete subjects x 9 questions = 198 (label balance 103/95)

Interpretation
--------------
- The CLASSIFICATION pipeline is sound. The professor's own f1/f2/f3 ratios
  reproduce the paper: mean per-question accuracy 0.788 (inside the Table-2 range
  0.725-0.875) and score-level r 0.741 / MAE 1.09 (~ the thesis test r 0.74,
  MAE 1.0). So 3 state-proportions ARE enough to predict correct vs incorrect
  answering, and eqs.7-9 are implemented correctly.
- OUR SRI does NOT predict correctness: mean accuracy 0.581 is BELOW the mean
  per-question majority baseline (0.611) and score r is ~0 (0.135). Our Layer-1
  K-medoids macrostates are not reproducing the professor's partition. The gap is
  in Layer-1 fidelity, NOT in Layer-2.

Diagnostics (scripts/, stdout saved next to this report)

   NO. our band-power vs f1/f2/f3: max|r| 0.059, mean|r| 0.038 (value MAE

2. exp_channel_order.py -- does a different 19-channel column order fix it?
   NO. identity / lr_swap / reverse / 2x random permutations all give best|r|
   <= 0.054 and Layer-2 AUC <= 0.590 (vs the professor's 0.850). lr_swap is
   exactly identity (the 11 task channels are symmetric pairs + midline, so a
   left-right swap is a no-op). Across seeds 0-4 the identity AUC swings
   0.362-0.474 -> K-medoids is seed-unstable. Channel order is ruled out.

Conclusion / next steps
-----------------------
f1/f2/f3 are the professor's SRI; the deliverable is feature-correct and the only
gap is the Layer-1 partition. Confirm with the professor, in priority order:

- the exact 19-channel column order (still assumed; ruled out as the cause here,
  but unconfirmed).
